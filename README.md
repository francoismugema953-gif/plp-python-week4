# PLP Python Week 4 Assignment

* `welcome.py`: Refactors repeated print statements into a single reusable greeting function called three times.
* `toolbox.py`: Implements a mini-toolbox of helper functions (`double`, `is_pass`, and `greet`) with default arguments and tests them.

The `greet` function with optional arguments was slightly tricky to design at first to ensure the formatting matched the exact expected comma and exclamation placement correctly without hardcoding the default word into the output template string.
